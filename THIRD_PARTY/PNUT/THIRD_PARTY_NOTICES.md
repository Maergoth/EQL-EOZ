# PNUT M&M

Eye of Zomm's compact overlay layout and interaction patterns are translated
from PNUT M&M's MIT-licensed Qt UI at commit
28bbf8d39fdd52074c39cf2542ec65f7ccf104f0:

- mnmparse/app/overlay.py: header, tabs and compact metric table
- mnmparse/app/timer_panel.py: radial timer rows and remaining-time counters
- mnmparse/app/attack_bar.py: compact observed attack bar

Source: https://github.com/Maergoth/pnut-mnm
Copyright (c) 2026 PNUT M&M contributors. See MIT.txt.

The layout is implemented in Electron/HTML/CSS with EQL colors. PNUT's Python
runtime, Revenge and Elitist/Carebear features are not included.
