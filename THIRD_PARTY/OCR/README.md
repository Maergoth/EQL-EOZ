# Local OCR runtime

Eye of Zomm uses Tesseract.js **7.0.0**, Tesseract.js-core **7.0.0**, and the
English language distribution **@tesseract.js-data/eng 1.0.0**. They are unchanged
upstream runtime packages, pinned in package-lock.json. `prepare-ocr-assets.mjs`
copies their resolved dependency closure, worker and English model into the
release's `resources/ocr-runtime` directory. That directory's asset manifest
records every file's size and SHA-256. OCR does not require a network service or
an independently installed system Tesseract executable.

Tesseract.js and its WASM core use Apache-2.0; see [APACHE-2.0.txt](APACHE-2.0.txt).
English trained data is distributed by the [naptha/tessdata project](https://github.com/naptha/tessdata),
whose repository license is Apache-2.0; its English npm package additionally
declares MIT in package metadata. The selected `4.0.0_best_int` English data is
the integerized LSTM model described by that project. Preserve both its package
metadata and the upstream Apache notice when redistributing the runtime.

Upstream sources:

- https://github.com/naptha/tesseract.js/tree/v7.0.0
- https://github.com/naptha/tesseract.js-core/tree/v7.0.0
- https://github.com/naptha/tessdata/tree/gh-pages
- https://registry.npmjs.org/@tesseract.js-data%2feng/1.0.0

The external runtime also includes these resolved supporting packages, with their
original license files and package metadata preserved in their directories:
`bmp-js`, `idb-keyval`, `is-url`, `node-fetch`, `opencollective-postinstall`,
`regenerator-runtime`, `wasm-feature-detect`, `zlibjs`, `whatwg-url`, `tr46` and
`webidl-conversions`. The generated manifest lists the precise resolved versions.

The synthetic item/stat images in `tests/fixtures/screen-read/` are project test
content generated by `scripts/create-ocr-fixtures.mjs`; they contain no game
artwork, proprietary screenshots or player/account data.
