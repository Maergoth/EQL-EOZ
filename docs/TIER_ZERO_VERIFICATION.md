# Tier-zero verification category

New item contributions made from ranked or reverse-calculated observations carry
their existing tier-zero verification note and
`[[Category:Tier 0 Verification Needed]]`. Manual preview/publish and automatic
captured-item publication use the same serializer. An ordinary tier-zero or
unranked draft is not assigned a fabricated verification state.

Editing an existing item through EoZ also adds this category when its Itempage
notes contain one of the app's generated recovery warnings. This includes a
subsequent automatic log-source addition. Membership is checked without case or
underscore differences; an existing manual category/sort key is retained.

Application-generated membership has an `EoZ: tier-zero verification category`
HTML marker. The existing independent tier-zero evidence and review checks must
pass before EoZ clears its recovery notes and marked category. It preserves
other notes, protected examples and manually maintained categories. A manually
assigned verification category can still be removed through the wiki editor.

This is a contribution-time change, not a batch edit of existing wiki articles.
The live category description is managed separately from application source.
